## What is TopoGraphica?

TopoGraphica treats elevation as drawable structure. Heightmaps and related spatial data become contour-led compositions you can study, plot, or push toward generative art. Because it runs on Processing, it fits creative-coding habits while still inviting open-ended experiments.

Reach for it when you need to read elevation structure clearly, try alternate render looks, or stage geometry for a pen plotter. Interactive terrain drawing, several modes, and live controls keep the path from raw data to finished lines flexible.

## How to work with it

Load a heightmap or another supported terrain source, then use the controls to steer density, style, and presentation. Flip between modes when you want side-by-side reads of contours and line character.

Common loop:
1. Bring in or synthesize terrain.
2. Adjust parameters while the sketch runs.
3. Review contour and 3D line previews.
4. Export once the piece feels finished.

If you plot on paper, match the exported lines to whatever format your plotter stack already expects.
